🔐 Human Verification Login Page
A modern login page built using HTML, CSS, and Vanilla JavaScript featuring a dynamic Integration-based Human Verification System instead of a traditional CAPTCHA.
✨ Features
Responsive centered login form
Name & Password validation
Randomly generated integration question
JavaScript-based answer verification
Error message for incorrect answers
Animated success screen
Gradient UI with modern design
Works fully offline
🛠 Tech Stack
HTML5
CSS3
JavaScript (No external libraries)
🚀 How It Works
On page load, a random integration question (e.g., ∫(2x dx)) is generated.
Login is allowed only if:
Fields are not empty
The integration answer is correct
After successful verification, a stylish animated success screen is displayed.

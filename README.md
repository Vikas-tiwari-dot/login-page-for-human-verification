🔐 Human Verification Login Page (Math Integration CAPTCHA)
A modern and interactive Login Authentication UI built using HTML, CSS, and Vanilla JavaScript, featuring a dynamic Math Integration-based Human Verification System instead of a traditional CAPTCHA.
This project demonstrates front-end UI design, DOM manipulation, input validation, and dynamic content generation — all without using any external libraries.
🚀 Live Project Overview
This login page includes:
✔️ Centered modern login form
✔️ Name & Password validation
✔️ Dynamically generated integration question
✔️ JavaScript-based verification logic
✔️ Animated success screen
✔️ Fully responsive design
✔️ Works completely offline
🧠 Human Verification Logic
Instead of using a traditional CAPTCHA, this system generates a random simple integration question when the page loads.
Example Questions:
∫(2x dx)
∫(3x² dx)
∫(5x³ dx)
The user must enter the correct integral answer.
Login Conditions:
Login is successful only if:
Name field is NOT empty
Password field is NOT empty
Integration answer is correct
If incorrect:
❌ Error message is shown in red
❌ Login is blocked
